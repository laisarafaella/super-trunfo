# SUPER TRUNFO 🃏
Projeto desenvolvido em C para simular o cadastro e a comparação de duas cartas do jogo Super Trunfo de Países.

# 📌 Descrição
O projeto foi desenvolvido em três níveis:
- Nível básico: cadastro e exibição das cartas
- Nível intermediário: cálculo de densidade populacional e PIB per capita
- Nível avançado: cálculo do Super Poder e comparação entre cartas
- Nível mestre: adição de interatividade com menus, escolha de atributos para comparação e utilizando dois atributos diferentes, com soma dos valores para determinar a carta vencedora


# 🛠️ Funcionalidades
✔ Cadastro de duas cartas via teclado

✔ Armazenamento de dados em variáveis apropriadas

✔ Exibição organizada das informações das cartas

✔ Cálculo da densidade populacional

✔ Cálculo do PIB per capita

✔ Cálculo do Super Poder das cartas

✔ Comparação entre cartas por atributos

✔ Menu interativo para escolha de atributos

✔ Comparação utilizando dois atributos diferentes

✔ Soma dos atributos para determinar o vencedor

✔ Tratamento de empates

✔ Exibição clara do resultado da rodada
