# SUPER TRUNFO 🃏
Projeto desenvolvido em C para simular o cadastro e comparação de duas cartas do jogo Super Trunfo de Países.

# 📌 Descrição
O projeto foi desenvolvido em três níveis:
- Nível básico: cadastro e exibição das cartas
- Nível intermediário: cálculo de densidade populacional e PIB per capita
- Nível avançado: cálculo do Super Poder e comparação entre cartas

# 🛠️ Funcionalidades
✔ Leitura de dados via teclado
✔ Armazenamento em variáveis apropriadas
✔ Cálculo da densidade populacional
✔ Cálculo do PIB per capita
✔ Cálculo do Super Poder
✔ Comparação automática dos atributos
✔ Exibição organizada dos resultados
